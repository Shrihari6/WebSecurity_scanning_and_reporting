# Web Security Project

## Project Overview
This project is a web-based application designed to integrate and automate basic web security tools like **Nmap** and **Nikto**. The platform provides users with a simple interface to:

- **Run security scans** for vulnerabilities.
- **View detailed reports** generated by the tools.
- **Learn about cybersecurity tools and techniques.**

The project uses **Flask**, a lightweight Python framework, to handle the backend and serves a clean, user-friendly frontend.

---

## Features

1. **User Authentication:**
   - Login functionality ensures only authorized users can access the dashboard and tools.
2. **Scanning Tools:**
   - **Nmap:** Performs network vulnerability scans.
   - **Nikto:** Scans web servers for potential security threats.
3. **Reports Management:**
   - View and download scan results.
4. **Responsive Design:**
   - Styled using CSS to provide a clean, accessible interface.
5. **Dynamic Routing:**
   - Routes dynamically manage user requests and serve pages.

## Prerequisites

1. Python 3.10 or above
2. Flask
3. Nmap and Nikto installed on the system

---

## Setup Instructions

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your_username/web_security_project.git
   cd web_security_project
   ```

2. **Set Up Virtual Environment:**
   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux/Mac
   venv\Scripts\activate    # Windows
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application:**
   ```bash
   python app.py
   ```

5. **Access the Application:**
   Open your browser and navigate to `http://127.0.0.1:5000`.

## Usage

1. **Login:** Use your credentials to log in.
2. **Dashboard:** Access tools like Nmap and Nikto from the dashboard.
3. **Run Scans:** Enter the target details and run scans.
4. **View Reports:** Navigate to the "Reports" section to view or download scan results.
