# Web Security + Automation Project

## Overview
A Flask-based project implementing secure web practices, automated CI/CD, and vulnerability scanning.

## Features
- Secure Authentication
- CI/CD with GitHub Actions
- Deployed on Heroku
- Vulnerability Scanning with Nikto and OWASP ZAP
- Monitoring with Sentry and New Relic

## Setup
1. Install dependencies: `pip install -r requirements.txt`
2. Run the app: `python app.py`

## Deployment
Deployed on Heroku: [Live Link](https://your-app.herokuapp.com)
